# DevOmX Website

Official DevOmX marketing website built with Vite, React, TypeScript, and Tailwind CSS.

## Local Development

Requirements:

- Node.js 18+
- npm

Run locally:

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
npm run preview
```

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Testing

```sh
npm run test
```
